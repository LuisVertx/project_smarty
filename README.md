# Project Smarty

Небольшой блог на PHP 8 + MySQL + Smarty.

## Возможности

- Главная страница с категориями и последними статьями
- Страница категории
- Сортировка статей по дате и просмотрам
- Пагинация в категории
- Страница статьи
- Увеличение просмотров
- Похожие статьи
- Сидинг тестовыми данными

## Технологии

- PHP 8
- MySQL
- PDO
- Smarty
- Composer
- Git

## Структура проекта

- `app/` — контроллеры, модели, core-классы
- `config/` — настройки подключения к БД
- `database/` — SQL-схема
- `public/` — точка входа и статические файлы
- `templates/` — шаблоны Smarty
- `storage/` — временные файлы Smarty

## Запуск

1. Создать базу данных из `database/schema.sql`
2. Настроить `config/database.php`
3. Установить зависимости:
   ```bash
   composer install
   
Команда для запуска встроенного сервера:
